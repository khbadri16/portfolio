pymembrain.netlify.app

Master's project2026Python framework

PyMembrain

A Python framework for membrane computing (P systems). You describe a tree of compartments, write guarded rewrite rules with a decorator, and the engine evolves the whole system in maximally parallel, nondeterministic steps.

  • Rules are plain methods declared with @when; object types come from type hints, so there is no DSL to learn.
  • Guard lambdas are analysed through Python's AST and compiled to in-memory SQLite queries, with an automatic Python fallback.
  • Optional process-based parallelism: each membrane can evolve in its own process.
  • Zero third-party dependencies, plus a full documentation site with an interactive visual tour.
  • Python 3.10+
  • SQLite
  • AST analysis
  • multiprocessing
  • GPL-3.0

transit-generator.vercel.app

Real-world tool2026Full-stack web app

Transit Document Generator

A web app for a customs transit office. Enter a shipment once and generate every document it needs (purchase orders, engagement letters, per-container dock forms, invoices and declarations) as ready-to-print Word and PDF files.

  • React and TypeScript front end with a FastAPI serverless back end, deployed together as one Vercel project.
  • AI-assisted tariff annex: Gemini or Claude reads an invoice and suggests HS codes for each product.
  • Container tracking across shipping lines (MSC, Maersk, CMA CGM, COSCO and more) and a label editor that exports print-ready PDFs.
  • Bilingual French/Arabic interface, with shared office data stored in Redis.
  • React
  • TypeScript
  • Tailwind CSS
  • FastAPI
  • docxtpl
  • Upstash Redis
  • LLM APIs

metaheuristics-lab.vercel.app

Personal project2026Algorithms

Metaheuristics Lab

An interactive playground where five strategies race to solve the travelling salesman problem on the same map with the same compute budget: nearest neighbour, hill climbing, simulated annealing, a genetic algorithm and the bees algorithm.

  • 2-opt moves scored in O(1), plus a time-sliced runner that gives every algorithm a fair share of CPU.
  • Seeded, reproducible runs; maps are shareable through the URL.
  • 14 unit tests, including reaching the known optimum on convex maps.
  • JavaScript
  • Canvas
  • Metaheuristics
  • node:test

Personal project2026E-commerce

Medina Atelier

A demo online store for handmade Algerian crafts: search and filters, product variants, a cart, cash-on-delivery checkout with delivery fees per wilaya, order tracking, and an admin back office.

  • An API layer that re-validates every order and recomputes prices server-side, never trusting the client.
  • Stock conflicts handled with HTTP-style 409 errors, plus an order-status state machine that restocks on cancel.
  • XSS-safe templating and 23 unit tests.

  • REST-style API

Problem Solving: state-space search

Solves a grid-covering puzzle (visit every target cell in one continuous path) and compares uninformed and informed search on 8 benchmark boards.

  • tkinter visualiser that animates the solution path.
